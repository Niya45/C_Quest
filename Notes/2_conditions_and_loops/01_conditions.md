# Conditional Statements

## Operators : 

- `<` : lessthan
- `>` : greater than
- `<=` : lessthan or equal to
- `>=` : greater than or equal to
- `==` : equal to
- `!=` : not equal to


- `&&` : and
- `||` : or
- `!` : not

## Compound Statement

```c
if (bool) { // if bool is true
    "Do this"
} else {
    "Do this"
}

if (!bool) { // if bool is false
    "Do this"
} else {
    "Do this"
}

if (1) {} // true
if (2) {} // false
```
